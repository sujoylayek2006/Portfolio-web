## ✨ Overview

This portfolio showcases the engineering work, full-stack systems, developer tooling, and certifications of **Sujoy Layek**, a B.Tech Computer Science & Engineering student at NSHM Knowledge Campus Durgapur.

Designed with an **editorial dark luxury aesthetic**, featuring smooth micro-interactions, responsive 3D perspective hardware stages, and lightning-fast static prerendering.

---

## 🚀 Key Features

- **Editorial Aesthetic & Ambient Lighting:** Floating GPU-accelerated glow mesh orbs, luxury display typography, and dark low-contrast background palette.
- **Infinite Scrolling Marquee Banner:** Smooth ticker looping core engineering principles and domain keywords.
- **3D Interactive Laptop Stage:** Draggable and clickable perspective carousel presenting projects inside a custom-rendered MacBook hardware mockup.
- **Curated Projects Showcase:**
  1. **NGO Digital Connect** (`01`): Full-stack NGO discovery and donation platform with real-time intake and AI verification.
  2. **RenameX** (`02`): High-efficiency batch file renamer and developer automation utility.
  3. **MultiFileMaker** (`03`): Scalable multi-file generation tool for rapid workspace scaffolding.
- **Engineering Matrix & Certifications:** Interactive skill badges across Frontend, Backend, Systems, and Tools, alongside verified credentials from **IBM**, **Oracle**, **AWS**, and **Udemy**.
- **Serverless Contact Form:** Zero-backend form integration with anti-spam honeypot, 1-click email copy to clipboard, and instant toast notifications.
- **Search Engine Optimization (SEO):** Native `robots.ts` and `sitemap.ts` dynamic route generation, OpenGraph metadata, and 100% semantic HTML structure.

## 💻 Getting Started Locally

### 1. Prerequisites
- **Node.js**: v18.18.0 or later (v20+ recommended)
- **npm**: v9+ or **pnpm** / **yarn**

### 2. Clone the Repository
```bash
git clone https://github.com/sujoylayek2006/Portfolio-web.git
cd Portfolio-web
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 5. Production Build
```bash
npm run build
npm run start
```
